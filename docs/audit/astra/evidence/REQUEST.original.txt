Branchcade is a sophisticated browser-based robotics educational application.

Its purpose is to help learners understand programming logic by observing actual simulated robot behavior, making predictions, investigating mistakes and testing alternative explanations.

Its core learning cycle is:

**Observe → Predict → Execute → Compare → Investigate → Experiment → Transfer → Reassess.**

The application uses:

- React.
- TypeScript.
- Vite.
- React Router.
- Blockly.
- A custom deterministic robot simulation engine.
- A safe bounded AST interpreter.
- IndexedDB local-first persistence.
- Structured execution traces.
- Misconception-based learning algorithms.
- Eight authored robotics missions.
- Team learning.
- Instructor and learner dashboards.
- Vitest and Playwright.
- GitHub Actions.

The original master specification spans Parts A–L.

Previous development agents built and verified those parts.

Do not start over.
