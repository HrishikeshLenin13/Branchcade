## Explicit semantics

- Signed negative movement/turn means backward/left. Zero moves/turns are errors. Stop ends the entire program, including inside a helper. A helper returns at the end of its body; definitions alone do not execute. Variables are run-global, typed on first assignment and cannot change type; there are no function parameters, break or continue blocks.
- AND/OR short-circuit. Guard a distance comparison with `is detected(distance) AND distance < threshold`. Unprotected null comparison is a source-linked error. A reading displayed20.0 may compare using19.96; the exact operands are shown in the comparison event and the precision rule is explicit.
- The trace is deliberately bounded rather than streaming forever. Every new motion tick has a stored authoritative snapshot. Consequently an evicted cache entry always has an exact event snapshot; missing/corrupt persisted traces are regenerated from versioned world/program inputs, with program/world/trace hashes verified during import. There is no rewind mutation of the live interpreter.
- The async UI runner is cooperative main-thread batching, not a Web Worker. Every batch is bounded, cancel is a real AbortSignal, and no remote execution exists. Reduced motion suppresses interpolation without changing outcome.

## Earlier records and regressions

An optional `engineVersion` on attempts/team results is2 for new runs and absent/1 for A–E. The isolated legacy interpreter, validator, world shape, motion and sensor rules preserve prior hashes and goal facts. Version2 is selected explicitly for new records. Legacy records keep their original action snapshots; their fixed-tick button is disabled rather than mislabeled. New world imports enforce current bounds; historical attempt snapshots retain their original valid world shapes.

`legacy-golden.json` fixes40 pre-F starter/reference/transfer fingerprints (the array length is asserted by the regression test). The regression checks compare every hash, final robot and error; mixed-version imports also reject a forged engine selector. All original A–E browser flows remain tested. The deliberate updated expectations are Part-F null errors, explicit Stop & Edit before authoring, and the Step code label; none are blanket skips.
