# Optional human review protocol — not yet performed

Use responsible adult/instructor authorization as appropriate. No real identities, sensitive details, faces or voice recordings are needed. This is a usability exercise, not evidence of medical or educational efficacy.

1. Before: ask what a robot at 24cm will do when its program stops only if distance <20, and ask why.
2. Task: open the app, start a local alias, predict, run, locate the actual branch and sensor value.
3. Task: inspect a diagnostic probe; change one threshold in the experiment and describe what changed.
4. After: use different numbers, for example 32cm and threshold35, then ask for the branch explanation.
5. Ask nonleading questions: What was confusing? Which step helped you figure out the result? Was the role handoff understandable?
