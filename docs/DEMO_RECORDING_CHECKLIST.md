## Capture on macOS

Shortcut/microphone workflow checked against [Apple’s screen-recording instructions](https://support.apple.com/en-au/102618) on 2026-10-24; rehearse on the owner’s actual macOS version.

- [ ] Press **Shift–Command–5** and select the screen-recording control for the chosen portion. In Options, choose a private save destination and intended microphone if narrating. macOS controls can vary by version; verify a short local test before the full take. QuickTime Player → File → New Screen Recording is another route into the capture UI.
- [ ] Record a 10-second test: voice clear, input meter/recorded sound present, fan/noise acceptable and no clipping. Use a quiet room; a headset mic is adequate. The app has no autoplay audio to capture.
- [ ] For separate narration, record your actual voice in the chosen recorder and align it to real footage. Screen-only footage is sufficient; do not include minors' faces/voices without appropriate separate permission.
- [ ] Capture the full authentic flow, with deliberate wrong choices visibly labeled demonstration. Wait for actual trace/result and durable-save acknowledgment. Never splice a different program's result as the current run.
- [ ] Stop using the recording control/menu-bar stop. Open the saved file and confirm it is a real playable recording before considering capture complete.

## Edit and inspect

- [ ] Use a local editor available to the owner. Make honest chapter cuts; preserve which values/code produced which outcome. A pointer/label overlay can explain a real state, not replace evidence. Do not speed up narration until unreadable.
- [ ] Add all entrant names, app name, one-sentence purpose, target audience, tools/languages, actual functionality and truthful AI/contribution statement. Avoid unnecessary music, unlicensed assets or proprietary logos.
- [ ] Produce readable captions/transcript and check math symbols/units manually (`<` must not become `>`). Keep titles/captions off the sensor/trace.
- [ ] Watch beginning to end at ordinary playback speed with headphones and without them. Check contrast, small text, cursor, all segment transitions and absence of private data.
- [ ] Measure the **exported file**, not the editor's planned timeline. Target 2:35–2:50, within the official 1–3 minute range. On macOS Finder Get Info / QuickTime Movie Inspector can report duration; if ffprobe is already installed, `ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 /absolute/path/to/demo.mp4` is an optional independent measurement, not a repo script.
- [ ] Save an inspected backup and label any later reuse as prerecorded. Do not claim that a still screenshot is a recording.
