# Part H acceptance — curriculum and missions

Scope: master-prompt Part H on top of the verified F and G work, main only. The eight existing missions (M01–M08) keep their ids and are improved in place as **mission data version 2**. Version 1 is frozen in `src/missions/mission-data/v1.json` so older attempts and team results are always judged with the rules they were made under.

## Measured, not assumed

- With the mission predictions (first action, branch, second question), **8 of 14** ideas can now surface automatically (7 before Part H): sensor-is-action, comparator, else-too, else-never, colour location, while pretest, loop count, definition-executes. Still only reachable through optional investigation: range reversed, strict vs inclusive, null as zero, call skipped, stale variable, sensor refresh.
- A real v1 defect fixed on the way: goals tied to the starter’s node ids (M06/M08 calls, M01/M03/M07 branches) would fail a correct program the learner rebuilt in the block editor.

## Honest limits

- Team mode judges with the new rules but has no hint ladder or second question.
- The solution is shown as read-only pseudocode; nothing is loaded into the learner’s program.
- No human study; teacher notes are authored guidance, not measured findings.
