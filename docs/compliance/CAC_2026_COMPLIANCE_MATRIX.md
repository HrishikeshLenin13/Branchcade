## Bottom line

The software works and is documented. **Whether the entry is eligible is not an engineering question, and it is currently the biggest risk.** The rulebook requires student coding and technical development, with AI only supporting specific aspects. The repository's own history records that AI agents wrote almost all of it.

Before submitting, the owner should:

1. Do and document real technical work personally.
2. Write an honest AI disclosure.
3. If unsure, ask the district office or the organizers in writing whether this history qualifies.

No one should attest otherwise.
