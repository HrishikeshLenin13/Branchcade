# Blockly editor media

These visual UI assets are copied without modification from the pinned `blockly@13.4.0` package (`media/`) under Apache-2.0; the complete upstream license is included beside them. Upstream: https://github.com/RaspberryPiFoundation/blockly. Robot and world illustrations elsewhere are original Branchcade assets.

`BlocklyEditor.tsx` points `media` to this same-origin directory. Blockly sounds are disabled and audio files are deliberately omitted. When updating the Blockly package, review and refresh these assets and the license together.
